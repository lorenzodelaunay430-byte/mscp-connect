MSCP Connect - version Flutter de départ

1. Dans ton projet Flutter existant, remplace ton dossier lib par celui du zip.
2. Remplace ton pubspec.yaml par celui du zip.
3. Dans le terminal du projet :
   flutter pub get
4. Lance :
   flutter run -d linux
   ou F5 dans VS Code.

Cette version comprend :
- Accueil
- Liste des machines
- Filtres
- Fiche machine
- EPI
- Risques
- Procédure d'intervention
- Navigation basse

Les photos réelles des machines, le QR code, les PDF et la 3D seront ajoutés dans les prochaines étapes.
